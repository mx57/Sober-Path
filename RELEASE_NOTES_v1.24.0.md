# Release Notes v1.24.0 🚀

## 🤖 AI-Коуч и Преодоление Паники
- **Новое CBT-упражнение «Преодоление тревоги и паники» (`anxiety_management`)**: Пошаговый соматический гид из 4 этапов для безопасной нейтрализации адреналиновых всплесков и мысленных петель.
- **Интеллектуальные Триггеры**: ИИ-Ассистент автоматически детектирует ключевые слова "паника", "паническая атака", "тревожность" и за пару секунд предлагает специализированную практическую помощь.

## 💬 Сообщество и Экстренная Помощь
- **Экстренный Импульс Помощи (`sendPanicSupportPulse`)**: Функция мгновенного извещения трезвого напарника или сообщества в момент острого приступа страха с вознаграждением +15 очков Кармы.

## 📚 Контент и Обучение
- **Новый микро-курс «Управление тревогой и паникой» (`anxiety_and_panic_control`)**: 3 обучающих урока о нейробиологии панических атак и соматической регуляции.
- **5 Новых Статей в Базе Знаний (ID 103–107)**:
  - ID 103: *Нейробиология панической атаки в трезвости*
  - ID 104: *Стимуляция блуждающего нерва (Vagus Nerve)*
  - ID 105: *Техника 5-4-3-2-1 при острой тревожности*
  - ID 106: *Диафрагмальное дыхание против гипервентиляции*
  - ID 107: *Соматическая терапия тревожных расстройств*
