## 🤖 AI-Коуч и Встроенные Упражнения
- **Новое CBT-упражнение "Преодоление тревоги и паники" (`anxiety_management`):** Пошаговый алгоритм физиологического и когнитивного заземления при острых приступах тревоги.
- **Интеллектуальные триггеры коуча:** Автоматическое обнаружение ключевых слов ('паника', 'паническая атака', 'тревожность', 'паникую', 'острая тревога') с мгновенной предложенной помощью.

## 📚 Контент и Обучение
- **Новый микро-курс "Управление тревогой и паникой" (`anxiety_and_panic_control`):** 3 структурированных урока с соматическими практиками, дыханием и проверочным тестом.
- **5 новых экспертных статей (IDs 103–107):**
  - ID 103: *Нейробиология панической атаки: как восстановить контроль за 3 минуты*
  - ID 104: *Соматическое заземление: телесные практики при тревожных расстройствах*
  - ID 105: *Преодоление токсичного стыда и чувства вины в выздоровлении*
  - ID 106: *Как распознать и нейтрализовать скрытые триггеры тревожности*
  - ID 107: *Техники когнитивной дефузии: работа с навязчивыми мыслями*

## 💬 Сообщество и Социальная Поддержка
- **Стикеры поддержки сообщества:** Реализован инструмент отправки виртуальных стикеров поддержки ("Обнимаю", "Горжусь тобой", "Так держать!", "Я рядом") с начислением +15 очков Кармы.
